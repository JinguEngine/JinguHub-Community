# JinguHub-Community

Catálogo público e versionado consumido pela aba **Comunidade** do Jingu Hub.

- Edite `communities.json` por Pull Request.
- Use somente links oficiais HTTPS.
- O Hub valida o schema antes de aceitar uma atualização remota.
- Uma cópia validada pode ser usada offline; o catálogo embarcado é o fallback final.
